# Gapless-Daily-Mean-LST-GEE
# Overview
This code estimates gapless daily mean land surface temperature (LST) on the Google Earth Engine (GEE) platform. It first derives gapped daily mean LST through linear combination, and then reconstructs gapless daily LST using the EATC model.
